Kocard新版桌面端注册登录与移动端打通

让中国大陆和国际用户在桌面端尽可能在对应地区注册登录。

适用端
macOS · Windows
做什么

登录前识别国内/海外，可手动切换；国内手机号或邮箱、海外邮箱；默认验证码，6 位自动提交；第三方按地区与移动端一致；首次登录自动注册；中英双语作用于全应用。

不做什么

不做独立注册表单；不做登录后切区；不做跨区账号合并或迁移；不新接移动端没有的第三方渠道。

怎么算完成

国内和海外账号都能登录；移动端账号（含第三方）在桌面进入同一账号；新用户不用单独注册；跨区账号有明确出路。

01 · 问题

这次要解决什么

国内和海外是两套账号。登录前看不出账号属于哪边，登错区就报“账号不存在”，会员和订单也带不过来。

现状 · 地区是隐式的

登录页不显示当前地区，也没有登录前切换入口。

约束 · 两套账号不互通

国内和海外分属两套服务器，会员和订单不跨区；登录后只能退出再换。

变化 · 移动端已有完整登录链路

iOS 先输入账号：默认验证码，6 位自动提交；密码登录是次级入口；第三方按地区展示；首次登录自动注册。

02 · 目标

目标与非目标

本期目标

  • ✓ 用户不用先懂地区就能登录打开就知道当前地区，识别错了能改。
  • ✓ 国内和海外各用对的方式国内手机号或邮箱；海外邮箱。
  • ✓ 和移动端用同一套登录方式验证码默认、密码可选；第三方渠道按地区一致；首次登录自动注册；移动端账号在桌面直接登录。
  • ✓ 地区和账号不串跨区账号有提示、能切换；登录后锁区。
  • ✓ 语言跟着用户走登录页中英切换，登录后全应用保持同一语言。

本期不做

  • × 不做独立注册表单验证码或第三方首次登录即注册，不另设注册页。
  • × 不做移动端之外的新渠道第三方只接移动端已有的 Apple、Google、Facebook。
  • × 不做登录后切区不提供应用内换区，也不合并、迁移账号或权益。
  • × 不做海外手机号海外账号输入只支持邮箱，不显示手机号入口。

衡量方式：上线后按周看登录成功率、跨区自助完成率、地区相关工单量；基线待补。

04 · 方案

方案概览

识别地区

按 IP + 系统语言推荐地区；页面常显当前地区。

输入账号

国内手机号或邮箱；海外邮箱。默认验证码，密码登录是次级入口。

验证身份

6 位验证码输满自动提交；也可切密码登录或第三方登录；勾选协议后才能发起；跨区账号先提示切换。

登录完成

首次登录自动注册；地区锁定，语言作用于全应用；换区先退出。

05 · 需求

功能需求

功能需求
编号 优先级 需求 验收标准
R-01 P0 地区识别与展示
启动或退出登录后，按 IP + 系统语言推荐地区，页面常显当前地区。移动端按 App Store 地区判定；桌面没有统一商店地区，按 IP + 系统语言推荐。识别中表单不可提交；IP 失败按系统语言兜底，仍无法判断让用户选，不默认国内。		 国内 IP + 中文显示国内；海外 IP + 英文显示海外；识别失败不阻塞，也不先闪错误地区。
R-02 P0 登录前切换地区
登录页有切换入口。确认弹窗说明：连另一套服务器，账号/会员/订单不跨区，登录后要退出才能换。确认后更新地区、账号规则和第三方渠道；语言不变；保留账号，清空验证码和密码；取消不改。手机号切到海外时保留原文，提交时提示改用邮箱，不静默清空。手动选择记在当前设备，下次启动优先。		 切到海外后手机号入口消失；账号保留（手机号保留原文，邮箱可直接沿用）；验证码/密码清空；切换不发登录请求；取消不变。
R-03 P0 账号规则
国内支持手机号或邮箱；海外只支持邮箱。默认验证码登录，密码登录是次级入口。账号为空不发请求；格式由服务端校验，桌面不另写一套手机号/邮箱规则。		 国内手机号和邮箱都能获取验证码；海外没有手机号入口；账号为空时按钮不发请求；格式错误显示服务端返回的原因。
R-04 P0 验证码登录（默认）
输入账号后点「登录 / 注册」获取 6 位验证码，进入验证码页；输满 6 位自动提交，不需要再点按钮；重发间隔 60 秒。首次使用自动创建账号，已有账号直接登录。		 验证码 6 位；输满自动提交；60 秒内重发不可点；首次手机号/邮箱登录后直接进入应用，不出现注册表单；再次登录进入同一账号。
R-05 P0 密码登录
「密码登录」进入账号 + 密码表单；「忘记密码」进入重置；「验证码登录」返回默认卡。账号或密码为空不发请求；失败保留账号和密码登录入口。		 默认卡可切密码登录并返回；密码为空不发请求；失败统一提示“账号或密码不正确”，保留账号；忘记密码可进入重置页。
R-06 P0 第三方登录
渠道与移动端一致：国内仅 Apple；海外 Google、Apple；服务端 Facebook 登录开关开启时海外增加 Facebook。授权成功后调统一第三方登录接口；已有账号进入同一账号，首次登录自动注册。		 国内只显示 Apple；海外显示 Google、Apple；开关开启时海外显示 Facebook，关闭时消失；首次第三方登录自动创建账号；再次授权进入同一账号；取消授权留在登录页。
R-07 P0 协议勾选
登录窗口底部常显勾选框和「我已阅读并同意《用户协议》和《隐私政策》」，两个链接可点；验证码卡和密码卡共用，切换登录方式保留勾选状态。默认不勾选；未勾选时点任一登录方式（验证码、密码、第三方）提示先勾选，不发请求；勾选后才能发起。每次重新进入登录页恢复未勾选。移动端不设勾选框，桌面端必须手动勾选。协议链接复用服务端配置；非中文使用国际版链接。		 默认未勾选；不勾选点任一登录方式，有提示且不发请求；勾选后可正常发起；切换验证码/密码卡勾选状态保留；重新进入登录页恢复未勾选；两个链接可打开；中英文链接指向对应版本。
R-08 P0 跨区账号处理
后端返回“账号属于另一地区”的独立错误码和地区字段；页面提示所属地区并可切换。切换后保留账号，重新获取验证码；不在错误地区自动注册、不合并、不报“密码错误”。		 国内页输入海外账号，出现跨区提示；确认后切到海外页、账号保留、验证码清空；取消留在原页；后端未返回该错误码时此条不通过。
R-09 P0 登录后锁区
登录后不提供切区，换区必须退出。退出后回登录页，保留上次地区，切换入口恢复。		 登录后的应用内找不到换区入口；退出登录后出现切换入口；切换不会在已登录状态静默发生。
R-10 P0 语言作用于全应用
登录页可切中文/English；选择持久化；登录后沿用；登录页文案全覆盖，不混排。		 切到 English 后登录页全部英文且无布局溢出；登录后应用主界面为英文；重启仍为英文；切回中文后一致。
R-11 P0 密码重置
从「密码登录」进入「忘记密码」；账号 + 验证码 + 新密码 + 确认新密码；验证码按重置密码场景发送，60 秒重发；新密码 6–18 位字母和数字组合；两次一致。成功后回登录页，账号保留。		 验证码错误、两次不一致、密码不合规分别提示；成功后回登录页且账号仍在；新密码可登录，旧密码不能登录。
R-12 P1 服务不可用与诊断
区分本地服务未启动和远端不可达；给说明、重试和诊断入口；诊断含版本、地区、错误码，可复制；不无限转圈。		 本地服务未启动显示启动指引；远端超时显示重试；重试成功后回到登录；诊断信息包含版本、地区、错误码。
R-13 P1 未激活账号的授权码步骤
服务端返回账号未激活，且授权码开关开启时，登录后进入授权码页；输入授权码确认后继续进入应用；可返回登录页。桌面是否开启由服务端开关决定，未配置或关闭时不出现。		 开关关闭时不出现授权码页；开关开启且账号未激活时出现；授权码正确后进入应用；错误时留在授权码页并提示。
06 · 状态

状态与异常

状态与异常
状态 触发条件 用户看到 如何处理
地区识别中 启动或退出登录后，IP 查询还未返回。 登录卡显示识别中，表单暂不可提交。 设超时；超时按系统语言兜底，别让用户干等。
识别失败 IP 服务失败，系统语言也无法判断。 地区选择，说明“无法自动识别，请选择”。 不静默默认国内；未选地区不能登录。
地区与语言不一致 海外 IP + 中文系统，或国内 IP + 英文系统。 地区按 IP，语言按用户选择；两者独立显示。 不要用语言反推地区；切换语言不改变地区。
切换地区确认 用户点切换入口。 弹窗列三条影响，可取消或确认。 确认后清空验证码/密码，保留账号，不发请求。
协议未勾选 勾选框未勾选时点任一登录方式。 提示先阅读并勾选协议，留在当前页。 不发请求；勾选后可继续；每次进入登录页默认未勾选。
验证码已发送 / 倒计时 点「登录 / 注册」或「重新发送」成功。 进入验证码页；显示 60 秒倒计时。 重发后旧码失效；倒计时期间重发不可点。
验证码发送中 / 失败 点「登录 / 注册」或「重新发送」后，请求未返回或失败。 发送中显示加载；失败提示原因，留在当前页，可重试。 成功才进入验证码页并启动 60 秒倒计时；失败不清空账号。
验证码自动提交中 输入第 6 位验证码。 自动提交，显示加载态；不需要再点按钮。 只发一次请求；提交中不接受重复输入。
验证码错误 / 过期 服务端判定验证码不正确或已过期。 提示服务端原因；账号保留，重新输入验证码后提交。 不清空账号；不把错误码当成功；过期引导重发。
密码错误 / 账号不存在 密码登录失败。 统一提示“账号或密码不正确”。 不暴露账号是否存在；跨区账号除外，走跨区提示。
跨区账号 登录时账号属于另一地区。 弹窗说明账号属于 X，可切换；切换后重新获取验证码。 必须用独立错误码；不在错误地区自动注册、不合并账号。
新用户自动注册 首次验证码或第三方登录，服务端判定为新用户。 直接进入应用，不出现注册表单。 记录注册事件；不要求补填账号资料。
第三方授权取消 / 失败 用户在授权页取消，或授权失败。 回到登录页，提示未完成登录，可重试。 取消不发起后端请求；不残留上次授权状态。
未激活账号 服务端返回账号未激活，且授权码开关开启。 登录后进入授权码页；输入正确后进入应用。 开关关闭时不出现；授权码失败留在页面并提示。
本地服务未启动 桌面端本地服务未运行。 “服务未启动” + 启动指引 + 重试。 不要显示远端不可达；不要无限转圈。
远端不可达 / 超时 账号服务网络失败或超时。 “无法连接” + 重试 + 诊断入口。 保留已填账号；不误报登录成功。
登录中重复点击 用户连续点登录或第三方登录。 按钮进入加载态，不可重复点。 只发一次请求；失败后恢复可点。
登录成功 验证码、密码或第三方授权通过。 进入应用；新用户已完成注册；地区锁定；语言沿用。 不再显示登录页；不提供切区。
