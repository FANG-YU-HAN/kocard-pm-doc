# KoCard 产品介绍

> 整理日期：2026-10-19 ｜ 基于公开调研与内部文档的自我梳理，随产品进展更新

## 一句话定位

KoCard 是一套面向影像创作者的「现场数据工作流」：硬件是入口（磁吸 SSD + 读卡器），软件是核心价值链（拷卡 → 哈希校验 → 转码 → 推送 → 报告），订阅制变现，数据恢复是按「能力模块复用」打法新开的产品线。

## 产品家族

### 1. KoCard（拷卡）— 主产品

影像创作者的现场数据管理 App（iOS / Android + DIT 桌面端）。拍完现场把卡里的素材安全落地：

- 多路径拷贝
- 哈希校验（核心价值链，产品的信任根基）
- HEVC 代理转码
- 推送至云盘 / NAS
- 报告与通知（主在 DIT 端）

渠道合作：SmallRig（SmallRig 制造销售磁吸 SSD 硬件，KoCard 提供软件与会员权益）、B&H 上架。

### 2. KoCard-GO — 自有硬件

磁吸移动 SSD：双卡槽、PD 100W 边充边拷、磁吸吸附。2026-10 在调研低价版方案：5Gbps 速度档 + 512GB，成本约为现款 GO 1TB 的六成。定位逻辑：「经济舱与商务舱同一架飞机」——低价版承接入门与走量（4K60 外录），4K120 专业需求留给 GO，两个 SKU 不打架。

### 3. KoCard-Rescue — 数据恢复能力模块（规划中）

1:1 对标万兴 Recoverit，能力全量对齐、体验差异化（轻、快、诚实、现代）。与 kocard-core 共用库同一套打法：做一次，KoCard 和 DEMAZE 两条产品线都能用；经查证两条产品线均无恢复能力，全新增量。

- 落点：KoCard Pro 桌面端（mac 起步）+ KoCard NAS 端（绿联 UGOS Pro 原生应用）+ DEMAZE 存储节点
- 节奏：1 名工程师 + agent 驱动，11 个双周迭代（约 5 个月），MVP 约 2 个月（mac 端 exFAT 卡误删 / 误格式化恢复全流程）
- 服务化差异点：软件无法恢复的场景可转实验室级人工恢复，按 case 报价——竞品止步于软件
- 坚决不做：退出挽留、好评分流等一切营销套路；成功率话术如实告知物理上限

## 核心商业逻辑（三层）

1. **信任是第一转化因素**。拷卡和恢复工具，用户决策核心都是「敢不敢把盘交给它」——所以产品原则强调诚实：找到 ≠ 能恢复、隐私口径不玩模糊、不做夸大宣传。
2. **模块化复用，边际成本接近零**。恢复等能力做成共用模块，随宿主安装包分发，付费 / 账号 / 更新复用既有体系。竞品从零获客，我们从存量用户转化。
3. **需求端有时间窗口**：iPhone 17 Pro 支持 ProRes RAW 直录外置 SSD、创作者经济持续扩张，移动端现场数据管理市场正在形成。

## 当前关键议题

- 转化漏斗与信任基础建设（收敛内购 SKU 为 免费 / Pro / Team 三档；统一隐私口径；集中滩头人群）
- KoCard-GO 与低价版 SKU 的取舍拍板
- KoCard-Rescue 模块评审与开工
